Participantes → menú "Participantes"

  • Registrar individualmente: ingrese cédula, nombres y apellidos en el formulario

Preguntas → menú "Preguntas" → pestaña E1, E2, E3 o E4
  • Nombre sugerido: test_01_preguntas.xlsx, test_02_preguntas.xlsx, test_03_preguntas.xlsx, test_04_preguntas.xlsx
  • Columnas requeridas: pregunta | A | B | C | D | respuesta
  • La columna respuesta debe contener solo A, B, C o D (mayúscula)
  • Se requieren mínimo 10 filas válidas por archivo

ℹ️ Los archivos se cargan desde esta interfaz (no desde una carpeta del sistema). Los datos se guardan en el navegador (localStorage).

Materiales por módulo

Ingrese la URL pública del archivo PPT para cada módulo. Los participantes verán un botón ⬇ Descargar presentación en la tarjeta del portal.

¿Cómo obtener la URL?
• Google Drive: Suba el archivo → clic derecho → "Compartir" → "Cualquier persona con el vínculo" → copie el ID del link y use: https://drive.google.com/uc?export=download&id=ID_AQUI
• GitHub: Suba el archivo a la carpeta slides/ del repositorio → abra el archivo → botón "Raw" → copie esa URL.
